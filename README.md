# Пульт для Яндекс Музыки

Музыка играет во вкладке браузера на компьютере, а управляете вы ей с телефона:
пауза, следующий и предыдущий трек, название и обложка текущей песни, «Моя волна»,
список «Мне нравится» и поиск треков.

Состоит из двух частей:

- `worker/` — облачный ретранслятор на Cloudflare Workers (бесплатный тариф).
  Он же отдаёт страницу-пульт для телефона.
- `extension/` — расширение для Chrome (и других браузеров на Chromium: Edge, Яндекс Браузер, Brave).

## 1. Разверните воркер (один раз)

Понадобится бесплатный аккаунт Cloudflare.

**Вариант А, без установки чего-либо на компьютер.** Загрузите папку `worker/` в новый
репозиторий на GitHub (можно через кнопку «Upload files» на сайте). Затем в панели
Cloudflare откройте Workers & Pages, создайте новый воркер через импорт репозитория
и выберите этот репозиторий. Cloudflare сам прочитает `wrangler.toml` и задеплоит.

**Вариант Б, через командную строку** (нужен Node.js):

    cd worker
    npm install
    npx wrangler login
    npx wrangler deploy

После деплоя вы получите адрес вида `https://ym-remote.ВАШЕ-ИМЯ.workers.dev`.

## 2. Установите расширение

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» (переключатель справа вверху).
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/`.

## 3. Свяжите телефон

1. Откройте Яндекс Музыку в браузере и включите любой трек.
2. Нажмите на иконку расширения, вставьте адрес воркера и нажмите «Сохранить».
3. Отсканируйте QR-код телефоном. На iPhone через «Поделиться → На экран „Домой“»,
   на Android через меню браузера «Добавить на главный экран» пульт можно
   открывать как приложение.

## Как это работает

    Телефон ──WebSocket──► Cloudflare (комната) ◄──WebSocket── расширение ──► вкладка Яндекс Музыки

Расширение перехватывает обработчики MediaSession, которые сам Яндекс регистрирует
для медиаклавиш, и вызывает их. Поэтому управление почти не зависит от вёрстки сайта.
Если какого-то обработчика нет, расширение нажимает кнопку плеера по её подписи.

Списки («Мне нравится», результаты поиска) расширение читает через API самого сайта
от имени открытой сессии. Чтобы включить трек, вкладка переходит на страницу списка
и нажимает кнопку у нужной строки, поэтому дальше музыка играет так же, как если бы
вы нажали сами (например, по лайкам). Если вкладка Яндекс Музыки скрыта за другой
вкладкой, расширение на пару секунд делает её активной и потом возвращает прежнюю:
скрытую вкладку сайт не перерисовывает.

Доступ к комнате защищён случайным 128-битным кодом из QR-кода. Кнопка «Сменить код»
в расширении отвязывает все ранее подключённые телефоны. Через ретранслятор проходят
названия треков, исполнители, ссылки на обложки и команды. Куки и токены Яндекса
никуда не передаются: запросы к API делает сама вкладка.

## Если что-то не работает

- **Пульт пишет «Вкладка закрыта», хотя она открыта.** Обновите вкладку Яндекс Музыки
  (после установки расширения это нужно сделать один раз).
- **Кнопки нажимаются, но ничего не происходит.** Откройте консоль на странице
  Яндекс Музыки (F12) и проверьте, нет ли ошибок. Скорее всего, сайт обновился,
  и нужно поправить `page.js` или подписи кнопок в `content.js`.
- **Открыто несколько вкладок Яндекс Музыки.** Команды уходят во вкладку, где сейчас
  играет музыка.
- **Пульт пишет «Вкладка Яндекс Музыки скрыта».** Окно браузера с ней свёрнуто —
  разверните его (оно может быть под другими окнами).

## Идеи для развития

Громкость и лайк, полоса прогресса с перемоткой, очередь треков, поиск
артистов и альбомов.
