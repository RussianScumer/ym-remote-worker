# Пульт для Яндекс Музыки

Слушаете Яндекс Музыку в браузере на компьютере? Управляйте ей с телефона,
как в Spotify Connect: пауза, следующий и предыдущий трек, обложка и название песни,
«Моя волна», список «Мне нравится» и поиск треков.

На компьютере ничего запускать не нужно: достаточно один раз поставить расширение для браузера.
На телефоне ничего устанавливать не нужно: пульт открывается как обычная страница.

## Что понадобится

- Компьютер с Chrome, Яндекс Браузером, Edge, Brave или другим браузером на Chromium
  (версия 116 или новее).
- Аккаунт Яндекс Музыки, в который вы вошли в этом браузере.
- Телефон с камерой, чтобы отсканировать QR-код.

## Установка (5 минут, один раз)

### 1. Скачайте расширение

1. Откройте страницу проекта на GitHub: https://github.com/RussianScumer/ym-remote-worker
2. Нажмите зелёную кнопку **Code → Download ZIP**.
3. Распакуйте архив в папку, которую не будете удалять (например, в «Документы»).
   Браузер загружает расширение прямо из этой папки, поэтому после удаления папки оно перестанет работать.

### 2. Установите расширение в браузер

1. Откройте в адресной строке `chrome://extensions`
   (в Яндекс Браузере — `browser://extensions`, в Edge — `edge://extensions`).
2. Включите **«Режим разработчика»** (переключатель справа вверху).
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `extension`
   из распакованного архива.
4. Закрепите значок расширения на панели: нажмите на значок пазла справа от адресной строки
   и на булавку рядом с «Пульт для Яндекс Музыки».

### 3. Подключите телефон

1. Откройте [Яндекс Музыку](https://music.yandex.ru) в браузере. Если вкладка уже была открыта,
   обновите её (F5).
2. Нажмите на значок расширения. Адрес сервера уже вписан, менять его не нужно.
3. Отсканируйте QR-код камерой телефона и откройте ссылку.
4. Добавьте пульт на главный экран, чтобы открывать его как приложение:
   - iPhone (Safari): **Поделиться → На экран «Домой»**;
   - Android (Chrome): **меню ⋮ → Добавить на главный экран**.

Готово. На пульте должен появиться статус «Компьютер на связи».

## Как пользоваться

1. Откройте Яндекс Музыку во вкладке браузера на компьютере. Вкладку можно оставить
   в фоне, а окно — под другими окнами. Сворачивать окно браузера не нужно (см. ниже).
2. Откройте пульт на телефоне.
3. Вкладки внизу пульта:
   - **Плеер** — что сейчас играет, кнопки «назад», «пауза», «вперёд» и «Моя волна».
   - **Мне нравится** — ваши лайкнутые треки. Нажмите на трек, чтобы включить его,
     или «Играть всё».
   - **Поиск** — введите название песни или исполнителя и нажмите на нужный трек.

Когда вы включаете трек из списка, вкладка Яндекс Музыки на секунду-две становится активной
в своём окне, а потом браузер возвращает вкладку, которая была открыта до этого. Так и задумано.

Пультом могут пользоваться друзья: каждый ставит расширение у себя и получает свой QR-код.
Чужой пульт к вашей музыке не подключится.

## Если что-то не работает

- **Пульт пишет «Вкладка с Яндекс Музыкой закрыта», хотя она открыта.** Обновите вкладку Яндекс Музыки (F5).
  После установки или обновления расширения это нужно сделать один раз.
- **Пульт пишет «Вкладка Яндекс Музыки скрыта — разверните её окно на компьютере».** Окно браузера с музыкой свёрнуто.
  Разверните его (можно оставить под другими окнами).
- **QR-код не появляется.** Проверьте, что в поле стоит адрес `https://ym-remote-worker.mishkailia2003.workers.dev`,
  и нажмите «Сохранить».
- **Открыто несколько вкладок Яндекс Музыки.** Команды уходят во вкладку, где сейчас играет музыка.
- **Хочу отвязать старый телефон.** Откройте расширение и нажмите «Сменить код».
  Все подключённые телефоны отключатся, новый QR-код нужно будет отсканировать заново.
- **Кнопки нажимаются, но ничего не происходит.** Скорее всего, Яндекс обновил сайт.
  Напишите автору или создайте issue на GitHub.

## Как обновить расширение

Скачайте свежий ZIP (шаг 1), замените им старую папку, затем на странице `chrome://extensions`
нажмите на значок обновления у расширения и обновите вкладку Яндекс Музыки.

## Безопасность

- Доступ к вашему пульту есть только у тех, у кого есть ваш QR-код (ссылка с длинным случайным кодом).
  Не публикуйте эту ссылку.
- Через сервер проходят только названия треков, исполнители, ссылки на обложки и команды
  вроде «пауза» или «следующий трек».
- Пароль, куки и токены Яндекса никуда не передаются: к Яндекс Музыке обращается
  сама вкладка в вашем браузере.

## Для разработчиков

Проект состоит из двух частей:

- `extension/` — расширение для Chrome (Manifest V3).
- `worker/` — ретранслятор на Cloudflare Workers + Durable Objects (бесплатный тариф).
  Он же отдаёт страницу-пульт.

    Телефон ──WebSocket──► Cloudflare (комната) ◄──WebSocket── расширение ──► вкладка Яндекс Музыки

Расширение перехватывает обработчики MediaSession, которые Яндекс регистрирует для медиаклавиш,
и вызывает их напрямую. Если обработчика нет, нажимает кнопку плеера по её подписи.
Списки («Мне нравится», поиск) читаются через API сайта от имени открытой сессии,
а трек включается нажатием кнопки в нужной строке на странице списка.

### Свой сервер

Можно развернуть собственный воркер и указать его адрес в расширении вместо адреса по умолчанию
(`DEFAULT_SERVER` в `extension/background.js`).

**Через GitHub, без установки чего-либо.** Сделайте форк репозитория. В панели Cloudflare
откройте Workers & Pages, создайте воркер через импорт репозитория и в настройках сборки
укажите Root directory `worker`.

**Через командную строку** (нужен Node.js):

    cd worker
    npm install
    npx wrangler login
    npx wrangler deploy

Локальный запуск: `cd worker && npx wrangler dev`.
